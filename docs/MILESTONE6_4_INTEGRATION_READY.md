## Contract change

`contracts/openapi.yaml` now documents the existing `GET /api/operator/mainnet/read-only` route exactly as implemented:

- `X-VeilPay-Operator-Token` is required through the `operatorReadToken` API-key security scheme and the matching required header parameter.
- The route is mainnet-only. It returns `401 UNAUTHENTICATED` before route work when the token is absent or incorrect, `404 NOT_FOUND` after authenticated routing when the configured network is not mainnet, and `503 WALLET_UNAVAILABLE` for absent, unsupported, stale, malformed, network-mismatched, or internally inconsistent viewing snapshots.
- The `200` response is `MainnetReadOnlySnapshot`: mainnet address, decimal zatoshi balance, wallet-reported sync height, `stale: false`, a wallet-reported received-output list, and an explicit `chainEvidence` boundary (`trusted: false`, `height: null`). It is not independent blockchain evidence or a settlement proof.
- The route documents that it cannot create a wallet, prepare, sign, submit, or broadcast a transaction.

`src/lib/contract/schemas.ts` contains the matching Zod schema for contract validation only; it is not exposed through the customer UI. `contract-sync.test.ts` now checks the exact path, method, header security, four status responses, successful schema reference, mainnet constant, and untrusted-evidence fields. `backend/tests/mainnet.rs` verifies the route's success shape, 401 error code, 503 error code, and authenticated non-mainnet 404 behavior.

## Remaining mainnet security blockers

The endpoint is only a read-only, adapter-injected foundation. A controlled mainnet ZEC payment remains blocked on a full ZIP-316 decoder, a dedicated non-spending viewing source, independently pinned chain evidence, production operator/agent authentication and secret management, key custody, fee and transaction decoding, explicit operator approval, durable single-broadcast reconciliation, merchant confirmation/reorganization monitoring, audit logging, alerts, backups, and a testnet/mainnet rehearsal. Automatic mainnet spending remains disabled.
